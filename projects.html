Just-A-RAG

Personal research project · Python · In development

A working prototype built to understand retrieval-augmented generation from the ground up rather than through a framework. Every stage of the pipeline is explicit, so each one can be swapped and measured on its own.

What it does

  • Ingests and chunks documents into retrievable passages.
  • Generates embeddings and stores them for vector retrieval.
  • Ranks retrieved context before it reaches the model.
  • Feeds that context into LLM-based generation for grounded answers.

Why it exists

  • A foundation for further experimentation with chunking strategies and retrieval quality.
  • A way to reason about where RAG pipelines actually fail — usually retrieval, rarely generation.

Advanced PDF Embed

Open-source WordPress plugin

WordPress has no good answer for showing a PDF in a post — the default is a link that dumps the reader into a browser viewer or a download folder. This plugin renders the document in place with PDF.js.

What it does

  • Embeds PDFs directly in posts and pages via PDF.js.
  • Keeps readers in the site's layout and styling.
  • Ships as a self-contained plugin — install and use, no build step.

yogeshjirel.com.np

Personal site · No framework, no build step

A portfolio that stays fast because there is almost nothing to load: hand-written HTML, three layered stylesheets and a handful of ES modules. No bundler, no framework, no runtime dependencies.

How it works

  • Components are ES modules — header, footer, filters, modals, scheduler — wired up by one entry point.
  • Content is authored as static HTML so crawlers and no-JS visitors see everything.
  • Scroll-reveal motion through IntersectionObserver, disabled under prefers-reduced-motion.
  • A GitHub Action regenerates the sitemap on every push to main.
  • The blog renders from a single posts.json file.
